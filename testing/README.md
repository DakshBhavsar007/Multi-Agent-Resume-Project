# 🧪 Between AI Question Paper Testing Files

Is folder me custom question papers available hain jinhe aap **Create Session Page (Step 3)** par upload aur test kar sakte hain:

---

## 📁 Files Included:

1. **`sample_mcq_question_paper.txt`**:
   - **Type**: MCQ / Aptitude Test
   - **Content**: 5 Computer Science & Aptitude MCQs with options and answer keys.
   - **How to test**: Step 3 me **Aptitude (MCQ) Round** card par `"Upload Custom Question Paper"` section me choose karein aur **"Extract Questions"** par click karein.

2. **`sample_coding_question_paper.txt`**:
   - **Type**: Technical Coding Test
   - **Content**: 2 DSA Coding Problems (*Two Sum Target* and *Reverse Words in a String*) with problem statements, example inputs/outputs, and constraints.
   - **How to test**: Step 3 me **Technical Coding Round** card par `"Upload Custom Coding Problems"` section me choose karein aur **"Extract Questions"** par click karein.

---

## 🚀 How to Test in UI:

1. App me `/sessions/new` (Create Session) page par jayein.
2. Step 1 (Job Details) aur Step 2 (Criteria) fill karke **Step 3 (Set Rounds)** par aayein.
3. **Aptitude Assessment Round** ya **Technical Coding Round** ke andar:
   - File selector me `testing/sample_mcq_question_paper.txt` ya `testing/sample_coding_question_paper.txt` attach karein.
   - **"Extract Questions"** button par click karein.
   - AI paper ko parse karke database me questions extract kark success message `✓ X questions extracted successfully` dikhayega!
